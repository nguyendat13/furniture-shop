# Furniture Shop 🪑🛒

Một ứng dụng web bán đồ nội thất được xây dựng với **Node.js** và **Express.js**.

## 🚀 Tính năng chính

- Xem danh sách sản phẩm
- Thêm sản phẩm vào giỏ hàng
- Đặt hàng và thanh toán
- Trang quản trị sản phẩm, đơn hàng, người dùng

## 🛠 Công nghệ sử dụng

- Node.js
- Express.js
- MongoDB / MySQL (tùy chọn)
- EJS / React / Vue (nếu có frontend)
- JWT / Bcrypt (nếu có xác thực)
- RESTful API

## 📦 Cài đặt

```bash
git clone https://github.com/nguyendat13/furniture-shop.git
cd furniture-shop
npm install

▶️ Chạy ứng dụng
npm start
